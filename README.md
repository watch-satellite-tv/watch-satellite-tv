# ماهواره زنده — Watch Satellite TV

پخش زنده‌ی شبکه‌های ماهواره‌ای، بدون دیش، با اینترنت — به‌صورت مینی‌اپ تلگرام.

- **دسته‌ی ایران:** ۲۸۵ شبکه (لیست iptv-org + تلوبیون/پرشیانا + ۴ آی‌فیلم + جم اسپورت + ۱۳ جم و ۸ پرشیانا از FATV + ۵۶ کانال فارسی‌زبان از FATV + ۱۵ کانال از جستجوی عمیق + جم سریز و جم سریز + از onetv.app — این دو از دیتاسنتر ۴۰۳ می‌گیرن، احتمالاً فقط ایران + آیفون، تست گوشی تعیین می‌کنه، بدون تکرار، با اسم‌های فارسی) — اولین دسته
- **دسته‌های کشور:** ۱۸۷ کشور (هر پلی‌لیست کشوری iptv-org که کانال دارد؛ 🇮🇷 ایران جدا به‌عنوان دسته‌ی فارسی اول است) — از 🇺🇸 آمریکا و 🇬🇧 انگلیس تا 🇯🇵 ژاپن و 🇧🇷 برزیل
- **دسته‌های موضوعی:** خبری، فیلم، ورزشی، موسیقی، سرگرمی
- **دسته‌ی سایر (🌍 سایر):** ۳٬۶۶۴ شبکه‌ی اضافی که فقط در streams.json هستن و توی هیچ پلی‌لیستی نیستن — همه‌ی لینک‌ها قبل از اضافه‌شدن تست شدن (۳٬۱۶۸ پلی‌لیست سالم تاییدشده + ۴۹۶ لینک نگه‌داشته‌شده با خطاهای غیرقطعی)؛ ۷۶۲ لینک مرده‌ی قطعی (۴۰۴، HTML به‌جای پلی‌لیست، تایم‌اوت بعد از چند دور تست) کنار گذاشته شدن
- **جمع کل:** ۱۹۴ دسته، ۱۹٬۸۷۵ ردیف، ۱۲٬۷۳۶ لینک https یکتا
- **جستجوی همه (Search All):** باکس جستجو همیشه در همه‌ی ۱۹۴ دسته با هم می‌گرده (پیش‌فرض)؛ نتایج بدون تکرار لینک، با برچسب کشور/دسته‌ی هر شبکه، تا بشه نسخه‌های مختلف یک کانال رو امتحان کرد — پاک‌کردن جستجو لیست دسته‌ی فعلی رو برمی‌گردونه
- **علاقه‌مندی‌ها:** ریفرش فید آیدی کانال‌ها رو عوض نمی‌کنه — ستاره‌ها بعد از ریفرش سر جاشون می‌مونن
- **پخش مستقیم:** hls.js، بدون پروکسی — گوشی مستقیم به CDN وصل می‌شه؛ قبل از هر تعویض شبکه پخش‌کننده کاملاً ریست می‌شه (pause + حذف src + load) تا یه شبکه‌ی خراب، پخش شبکه‌های بعدی رو قفل نکنه
- **چندزبانه:** فارسی، انگلیسی، چینی، عربی، روسی — انتخاب زبان در `/start` و داخل اپ
- **علاقه‌مندی و گزارش خرابی** برای هر شبکه
- **پنل ادمین:** آمار کاربرا (`/admin`) و پیام همگانی (`/broadcast`)
- **پیام به پشتیبانی:** دکمه‌ی «💬 پیام به پشتیبانی» زیر چت (مثل FontStory) — کاربر پیام می‌نویسه، برای ادمین میاد؛ ادمین با Reply به همون پیام جواب می‌ده و جواب به کاربر می‌رسه — به ۵ زبان

## معماری

- بک‌اند: Telegram Serverless (tgcloud) — بدون سرور، بدون هزینه
- دیتا: [iptv-org/iptv](https://github.com/iptv-org/iptv) (پلی‌لیست‌ها + streams.json) + [Persiana TV](https://github.com/Samhouston010/persiana-tv-epg)
- فرانت: `web/` (فارسی، RTL) → با `npm run build` به `dist/` ساخته می‌شه

## دیپلوی

```bash
npm install
cp owner.example.js tgcloud/lib/owner.js   # آیدی عددی تلگرام خودت رو بذار
npm run build
TGCLOUD_TOKEN='<token>' npx tgcloud push
TGCLOUD_TOKEN='<token>' npx tgcloud migrate --yes
```

توکن tgcloud و توکن بات رو هیچ‌وقت کامیت نکن — فقط از طریق متغیر محیطی یا داشبورد tgcloud استفاده کن.

فایل لوگوی v3 (webp) چون باینریه توی این ریپو نیست؛ `npm run build` بدون اون هم کار می‌کنه (فقط `dist/logo.webp` ساخته نمی‌شه). برای دیپلوی کامل، فایل لوگو رو کنار کد بذار.
